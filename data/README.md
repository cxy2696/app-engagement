# Data directory

- `raw/` contains the two aggregated panel exports tracked for reproducibility.
  They are research-use only; see [`../DATA_LICENSE.md`](../DATA_LICENSE.md).
- `processed/` and `processed-*/` are generated by `engagegraph data build` and
  are not tracked. Rebuild them from `configs/benchmark.yaml` or a domain profile.
- The raw weight unit is inferred to be milliseconds; see the data card.
